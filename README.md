
# Классификация речевых команд с использованием Log-Mel Filterbanks

  

В данном проекте реализован полный pipeline распознавания речевых команд с использованием **PyTorch**.

Основная цель работы — реализовать собственный слой извлечения признаков **Log-Mel Filterbanks** и обучить компактную **CNN-модель** для бинарной классификации речевых команд.

В задаче используются команды:

`yes` и `no`

Датасет: **Google Speech Commands**

# Реализация LogMelFilterBanks


В работе реализован собственный слой `LogMelFilterBanks` на основе базовых операций PyTorch.

  

```
Пайплайн обработки сигнала:
Аудиосигнал
↓
STFT (окно Ханна)
↓
Степенной спектр
↓
Mel-фильтрбанки
↓
Логарифм
```
  

Корректность реализации проверена сравнением с `torchaudio.transforms.MelSpectrogram`
После применения логарифма результаты совпадают.

# Архитектура модели

Используется компактная **Conv1d модель**.
Структура сети:

```
LogMelFilterBanks
↓
Conv1d
↓
BatchNorm
↓
ReLU
↓
MaxPool
↓
AdaptiveAvgPool
↓
Linear

```
Количество параметров модели:

~52K – 71K

# Проведённые эксперименты
## 1. Влияние числа mel-фильтров
Проверены значения:

`n_mels = 20`

`n_mels = 40`

`n_mels = 80`

Результаты показывают, что для данной задачи меньшее количество mel-фильтров может давать сопоставимую или более высокую точность.

---
## 2. Влияние параметра groups в Conv1d
Проверены значения:
groups = 2, 4, 8, 16
Анализировались:
- точность классификации
- время обучения
- количество параметров
- FLOPs модели

Групповые свёртки позволяют уменьшить вычислительную сложность модели без существенной потери качества.
